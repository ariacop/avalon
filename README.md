# آوالون (Avalon)

اپ وب موبایل‌فرست فارسی برای پخش نقش بازی Avalon.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس لوکال را روی موبایل/مرورگر باز کنید.

## قابلیت‌ها

- تعداد بازیکن قابل تنظیم (۵ تا ۱۰)
- چیدمان خودکار نقش‌ها بر اساس قوانین کلاسیک Avalon
- پخش تصادفی نقش‌ها
- کد محرمانه دو رقمی برای دیدن نقش
- استعلام ویژه مرلین، پرسیوال و نیروهای تاریکی
- کارت نقش گرافیکی با توضیح شیوا
